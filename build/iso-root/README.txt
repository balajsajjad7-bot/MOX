MOX Installer

Windows: open "Install MOX.cmd". Windows SmartScreen may warn you because the file
is unsigned. Choose More info, then Run anyway.
Intel Mac: right-click "Install MOX.command" and choose Open.
Apple silicon Macs can't run MOX.
Older PCs in Legacy BIOS mode: write this ISO to a USB drive with Rufus.

Your PC restarts once into the MOX installer. To undo before installing, run in
PowerShell as administrator: mox-setup.ps1 -Remove
